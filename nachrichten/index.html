Meldungen

Ausgewählte Meldungen mit kurzer Einordnung, nach Monat sortiert. Sie führen auf Seiten anderer Anbieter. Dort gelten deren Regeln.

So prüfst du eine Meldung
  1. Wer hat das veröffentlicht? Steht ein Medium, eine Behörde oder ein Institut dahinter?
  2. Wann ist es erschienen? Gibt es neuere Zahlen?
  3. Woher kommen die Zahlen? Wird eine Quelle genannt?
  4. Was sagen andere? Vergleiche mindestens zwei Quellen mit unterschiedlichem Blickwinkel.
  5. Passt es zum Gesamtbild? Eine einzelne Studie gegen alle anderen ist ein Warnzeichen. Prüfe, was die Forschung insgesamt sagt, zum Beispiel der Weltklimarat (IPCC).

Üben kannst du das am Klimawandel: Klimawandel: Quellen prüfen.
