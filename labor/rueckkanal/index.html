Rückkanal ohne Server: Ergebnis-QR

So kommen Gruppenergebnisse zur Lehrkraft, ohne Konto, ohne Server, ohne Datenübertragung ins Internet: Die Gruppe schreibt ihr Ergebnis, die Seite macht daraus einen QR-Code, die Lehrkraft scannt ihn mit der Kamera des Lehrer-Geräts. Alle Ergebnisse erscheinen gesammelt an der Wand. Die Daten stecken nur im Code.

0 von 280 Zeichen

Halte den Code vor die Kamera der Lehrkraft.

Die Kamera startet erst nach Antippen. Es wird kein Bild gespeichert.
